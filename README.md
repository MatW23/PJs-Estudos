🎮 Jogo do Número Secreto


📝 Descrição
O Número Secreto é um jogo interativo onde o usuário deve tentar adivinhar um número gerado aleatoriamente pelo sistema dentro de um intervalo específico (1 a 10). O projeto foi desenvolvido com foco em lógica de programação, manipulação do DOM e design responsivo.

🚀 Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:

HTML5: Estruturação dos elementos da página.

CSS3: Estilização, layout e efeitos visuais.

JavaScript (ES6+): Lógica do jogo e interatividade.

Node.js: Gerenciamento de pacotes e ambiente de desenvolvimento.

✨ Funcionalidades
[x] Geração de número aleatório.

[x] Validação de chutes.

[x] Feedback visual e sonoro (opcional) para acertos e erros.

[x] Contador de tentativas.

[x] Botão para reiniciar o jogo sem recarregar a página.


🧠 Aprendizados
Durante o desenvolvimento, pude praticar conceitos fundamentais como:

Manipulação de elementos HTML via JavaScript (document.querySelector).

Uso de funções para organizar o código.

Aplicação de condicionais (if/else) para verificar o acerto do usuário.

Integração de bibliotecas externas via Node.js para otimizar o fluxo de trabalho.
